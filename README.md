# Лабораторная работа №3. Очередь задач.

В данной лабораторной работе реализована очередь задач на языке C++. Очередь предназначена для хранения объектов типа Task и выполнения основных операций над ними: добавления, удаления, просмотра первого элемента и проверки очереди на пустоту.

Каждая задача содержит уникальный идентификатор, описание, приоритет и статус выполнения. Идентификатор используется для поиска задачи, удаления задачи и проверки наличия задачи в очереди. Приоритет показывает важность задачи. Статус выполнения показывает, выполнена задача или нет.

Важно, что пользователь сам выбирает значение идентификатора во время создания объекта Task через конструктор

Очередь реализована с использованием стандартного контейнера std::deque.

Проект состоит из нескольких файлов. В файле queue.hpp находятся объявления классов Task и Queue_Task. В файле queue.cpp находятся реализации методов этих классов. В файле main.cpp расположен пример работы программы. Для сборки проекта используется CMakeLists.txt.

Класс Task описывает одну задачу. В нём хранятся поля id, dscr, prior и status. Поле id отвечает за идентификатор задачи, dscr хранит текстовое описание, prior хранит приоритет, а status хранит информацию о выполнении задачи.

Для класса Task реализован конструктор по умолчанию, конструктор с параметрами, конструктор копирования, оператор сравнения и деструктор по умолчанию. Оператор сравнения позволяет сравнивать две задачи между собой.

Класс Queue_Task описывает очередь задач. Внутри класса используется контейнер std::deque<Task>, в котором хранятся все задачи. Также в классе хранится поле completed, которое отвечает за количество выполненных задач в очереди.

## Обязательная часть

В обязательной части реализованы основные методы очереди  
Метод enqueue добавляет новую задачу в конец очереди  
Метод dequeue удаляет первую задачу из очереди  
Метод front возвращает указатель на первую задачу  
Метод isEmpty проверяет, пуста ли очередь  

## Вариативная часть

Также реализованы дополнительные методы  
Метод size возвращает количество задач в очереди   
Метод clear полностью очищает очередь  
Метод print выводит все задачи на экран  
Метод find выполняет поиск задачи по идентификатору  
Метод erase удаляет задачу по идентификатору  
Метод comp_count возвращает количество выполненных задач  
Метод check проверяет, существует ли задача с заданным идентификатором  
Метод print_line выводит очередь в виде одной строки  

### Особенности

При добавлении новой задачи выполняется проверка на повторяющийся id. Если задача с таким идентификатором уже есть в очереди, новая задача не добавляется. Это нужно для того, чтобы каждая задача имела уникальный идентификатор.

Счётчик completed обновляется при изменении состава очереди. Если добавляется выполненная задача, счётчик увеличивается. Если удаляется выполненная задача, счётчик уменьшается. При полной очистке очереди счётчик сбрасывается в ноль.

В файле main.cpp показан пример работы программы. Там создаются несколько задач, после чего они добавляются в очередь. Далее выполняется вывод всех задач, поиск задачи по id, удаление задачи, проверка первой задачи, подсчёт количества задач и подсчёт количества выполненных задач. Также показывается очистка очереди и проверка, пуста ли очередь после очистки.

Для сборки проекта используется CMake. Основной исполняемый файл создаётся из main.cpp и queue.cpp, а папка include подключается как директория с заголовочными файлами.
